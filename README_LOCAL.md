# Локальный запуск бота

## Запуск в headless режиме (без открытия браузера)

Для запуска бота локально в фоновом режиме используйте:

```bash
python run_local.py
```

Бот будет работать в headless режиме - браузер не будет открываться, всё происходит в фоне.

## Остановка

Для остановки нажмите `Ctrl+C`.

## Что делает бот

1. **Ищет новые проекты** на Freelancehunt по категориям разработки
2. **Фильтрует по времени** - только проекты младше 24 часов
3. **Отправляет уведомления** в Telegram о новых проектах в категориях
4. **Автоматически оставляет отклики** на подходящие проекты
5. **Сохраняет проекты вне категорий** в отдельную таблицу (без уведомлений)

## Проверка работы

Бот будет проверять новые проекты каждую минуту (настраивается в `config.py`).

Для просмотра статуса откройте бота в Telegram и используйте команду `/status`.
