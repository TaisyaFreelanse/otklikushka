# 🚀 Запуск бота локально (фоновый режим)

## Быстрый старт

### Windows
```batch
run_local.bat
```

Или вручную:
```batch
set HEADLESS_BROWSER=true
python bot.py
```

### Linux/Mac
```bash
chmod +x run_local.sh
./run_local.sh
```

Или вручную:
```bash
export HEADLESS_BROWSER=true
python bot.py
```

## Что происходит:

1. **Браузер работает в фоновом режиме** (headless) - окно не открывается
2. **Бот подключается к Telegram** и ждёт команд
3. **Автоматическая проверка проектов** каждые 60 секунд (если включено через `/start` в боте)
4. **Уведомления в Telegram** о новых проектах
5. **Автоматическая отправка ставок** на подходящие проекты

## Настройка

### 1. Убедитесь что установлены зависимости:
```bash
pip install -r requirements.txt
```

### 2. Файл `cookies.json` должен быть в корневой папке:
- Запустите `python save_cookies.py` для сохранения cookies

### 3. Telegram Bot Token уже настроен в `config.py`

## Управление ботом

Откройте Telegram и найдите вашего бота, затем:

- `/start` - запустить автоматическую проверку проектов
- `/status` - проверить статус (включен/выключен)
- `/stop` - остановить автоматическую проверку
- Используйте кнопки в меню для управления

## Проверка работы

1. Откройте Telegram бота
2. Нажмите `/start` или кнопку "▶️ Запустить"
3. Бот начнёт проверять проекты каждую минуту
4. Когда появится новый проект - вы получите уведомление

## Логи

Логи будут выводиться в консоль. Вы увидите:
- Инициализацию браузера
- Загрузку cookies
- Проверку новых проектов
- Отправку ставок (если есть новые проекты)

## Остановка

Нажмите `Ctrl+C` в консоли или отправьте `/stop` боту в Telegram.
