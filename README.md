# Freelancehunt Auto-Bid Telegram Bot

Telegram бот для автоматического мониторинга и отклика на новые проекты на Freelancehunt.com.

## Возможности

- 🤖 Автоматический мониторинг новых проектов на Freelancehunt
- 📋 Фильтрация проектов по категориям
- 💰 Автоматическое создание ставок с генерацией текста через AI
- 📊 Управление через Telegram бота
- 📈 Отслеживание истории откликов
- ⚙️ Настройка суммы ставки и сроков выполнения

## Требования

- Python 3.8+
- Microsoft Edge (рекомендуется) или Google Chrome
- EdgeDriver (устанавливается автоматически с Selenium 4.0+)
- Аккаунт на Freelancehunt.com
- Telegram Bot Token
- Для входа требуется Google аккаунт (OAuth)

## Установка

1. **Клонируйте репозиторий или скачайте файлы проекта**

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Настройте переменные окружения:**
   - Скопируйте `.env.example` в `.env`
   - Отредактируйте `.env` и укажите ваш Telegram Bot Token:
   ```
   TELEGRAM_BOT_TOKEN=ваш_токен_бота
   ```

4. **EdgeDriver обычно устанавливается автоматически:**
   - Selenium 4.0+ автоматически управляет EdgeDriver
   - Если возникнут проблемы, скачайте вручную с [Microsoft Edge WebDriver](https://developer.microsoft.com/en-us/microsoft-edge/tools/webdriver/)

## Настройка Cookies для Freelancehunt

Перед запуском бота необходимо сохранить cookies вашей авторизованной сессии на Freelancehunt.

### Способ 1: Через скрипт (рекомендуется)

Запустите встроенный скрипт:
```bash
python save_cookies.py
```

Скрипт откроет браузер **Microsoft Edge**, вам нужно будет:
1. На странице Freelancehunt нажать кнопку **"Войти через Google"**
2. Выбрать ваш Google аккаунт и авторизоваться
3. Дождаться завершения процесса OAuth авторизации
4. Убедиться, что вы видите главную страницу Freelancehunt (вы авторизованы)
5. Вернуться в консоль и нажать Enter после успешной авторизации
6. Cookies будут автоматически сохранены в `cookies.json`

**Примечание:** Процесс входа через Google может занять некоторое время. Убедитесь, что вы полностью авторизованы перед нажатием Enter.

### Способ 2: Через браузер (вручную)

1. Авторизуйтесь на Freelancehunt.com в вашем браузере
2. Используйте расширение браузера для экспорта cookies (например, "EditThisCookie" для Chrome)
3. Сохраните cookies в файл `cookies.json` в корне проекта

**Формат cookies.json:**
```json
[
  {
    "name": "cookie_name",
    "value": "cookie_value",
    "domain": ".freelancehunt.com",
    "path": "/",
    "secure": true,
    "httpOnly": false
  }
]
```

## Использование

1. **Запустите бота:**
```bash
python bot.py
```

2. **В Telegram найдите вашего бота и отправьте команду `/start`**

3. **Основные команды:**

   - `/start` - Запуск бота и отображение информации
   - `/status` - Текущий статус работы бота
   - `/last_bids [N]` - Показать последние N откликов (по умолчанию 10)
   - `/toggle` - Включить/выключить автоматический отклик
   - `/settings` - Настроить категории проектов для отслеживания

4. **Настройка категорий:**

   Отправьте команду:
   ```
   /settings Веб-разработка, Дизайн, SEO
   ```

   Чтобы отслеживать все категории:
   ```
   /settings clear
   ```

## Настройка параметров

Все настройки находятся в файле `.env`:

- `TELEGRAM_BOT_TOKEN` - Токен вашего Telegram бота
- `FREELANCEHUNT_URL` - URL сайта Freelancehunt (по умолчанию: https://freelancehunt.com)
- `MAX_BID_AMOUNT` - Максимальная сумма ставки в гривнах (по умолчанию: 27000)
- `CHECK_INTERVAL` - Интервал проверки новых проектов в секундах (по умолчанию: 60)
- `ALLOWED_USER_IDS` - Список разрешенных пользователей (через запятую, оставьте пустым для всех)
- `HEADLESS_BROWSER` - Запуск браузера в фоновом режиме (true/false, по умолчанию: true)

## Как работает бот

1. **Мониторинг проектов:**
   - Бот каждые N секунд (настраивается в `CHECK_INTERVAL`) проверяет новые проекты
   - Фильтрует проекты по указанным категориям
   - Сохраняет новые проекты в базу данных

2. **Автоматический отклик:**
   - Для каждого нового проекта бот открывает страницу проекта
   - Нажимает кнопку "Сделать ставку"
   - Нажимает кнопку "Сгенерировать" для AI-генерации текста ставки (требуется Premium)
   - Рассчитывает оптимальную сумму и срок выполнения:
     - **Сумма:** Использует бюджет проекта (если указан), но не выше MAX_BID_AMOUNT
     - **Срок:** Использует указанный срок проекта (если есть), иначе 14 дней
   - Заполняет форму и отправляет ставку

3. **Уведомления:**
   - Бот отправляет уведомление о каждом отклике в Telegram
   - Сохраняет историю всех откликов в базу данных

## База данных

Бот использует SQLite базу данных (`freelancehunt_bot.db`), которая содержит:

- **projects** - информация о проектах
- **bids** - история всех откликов
- **settings** - настройки бота

## Решение проблем

### Бот не находит новые проекты

- Проверьте, что cookies актуальны (пересохраните их)
- Убедитесь, что вы авторизованы на Freelancehunt
- Проверьте правильность категорий в настройках

### Ошибки при отправке ставок

- Убедитесь, что у вас есть Premium подписка (для AI-генерации)
- Проверьте, что cookies не устарели
- Убедитесь, что проект еще доступен для отклика

### Браузер не запускается

- Убедитесь, что Microsoft Edge установлен (обычно предустановлен в Windows)
- Проверьте, что EdgeDriver совместим с вашей версией Edge
- Попробуйте запустить без headless режима (установите `HEADLESS_BROWSER=false`)
- Если проблемы с EdgeDriver, убедитесь, что используется Selenium 4.0+
